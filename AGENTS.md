# Power Grab TX Project Rules

## Primary task
Follow MORNING-BRIEFING-PROMPT-v9.md
for every morning briefing.

## Absolute restrictions
- Never run Git commands.
- Never commit, push or deploy.
- Never delete existing files.
- Never overwrite existing briefing pages.
- Never overwrite existing scheduled drafts.
- Never modify existing tracker entries.

## Allowed changes
Only:
1. Create today's scheduled-drafts markdown file.
2. Create today's new Astro briefing.
3. Prepend one entry to the trackers.astro entries array.

Only modify Layout.astro if the v9 prompt explicitly
allows it and description support is missing.

## Research integrity
- Never invent developments or sources.
- Verify publication dates.
- Check previous briefing coverage.
- Skip paywalled outlets.
- Stop if live research is incomplete.

## Execution
- Research must finish before creating site files.
- Never publish or deploy.
- Validate Astro after changes.
- Report all changed files.
- Report the briefing archive count.
